# Testing hygiene

Every test artifact (temp databases, renders, images, videos, downloads, clones, probe output) goes under one folder: run `python3 ~/.claude/hooks/hygiene/post_merge_hygiene.py test-start <run-id>`, which creates and prints `~/.test-runs/<run-id>/`, and put everything there instead of /tmp or a scratchpad. When the test is done run `... test-end <run-id>`; the hygiene sweep (every 15 minutes) then deletes the folder, and also deletes it if nothing in it changed for 60 minutes and no process has it open. Test folders inside Claude scratch folders (and any `hygiene.extra_test_roots` you list in `~/.claude/hooks/hook-skill.json`) whose names contain test, qc-, verify, probe, fixture, render, smoke, e2e, sandbox are swept after 6 idle hours unless a process holds them or they contain unpushed or uncommitted git work.
