# Agent Teams — OPTIONAL, and off by default

Teams are formed ONLY when the client asks for one in their own words (SKILL.md
step 16.9). "Warranted by shape" is not sufficient: everything a team supervises,
the five-minute tick and the gauntlet already enforce deterministically, and the
workflow lane is the visible, governed one.

**The full path lives in `references/optional/agent-team.md`** — the five-level
architecture, the four commanders and their charters, the Agent Teams probe, the
§4.1 trust pre-flight (required before the first spawn of every run — a fresh
build directory is always untrusted), the enablement/consent/restart/resume flow,
the disagreement protocol, the team-size gate, and §10, the single owner of
teammate-liveness verification (the teammate's own transcript decides; the inbox
artifact and `ListAgents` corroborate and can never ground a negative verdict).
Load that file only on the explicit ask; it is never read on a default run.
