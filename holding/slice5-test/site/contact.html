Design brief

This build follows the researched design brief for a dentist brochure site. Every hero and copy decision traces to it.

Site type: dentist / medical-practice brochure site
  • Hero structure: practice name + one-line patient-outcome promise, appointment CTA above the fold, trust strip directly under. Source: funnel-architecture.md §15 block A; Mobbin reference screens Fresha, Heidi, Care.com (web).
  • Layout systems: single column, fixed rhythm; one primary action per page; sticky booking bar on mobile. Source: funnel-architecture.md §15 block A.
  • Typography scale: 1.25 type ladder from 17px body (17/21/27/33/42/52); body 17px at 1.6 line-height. Source: funnel-architecture.md §15 block A.
  • Color systems: clean medical neutrals with ONE teal accent reserved for the appointment CTA. Source: funnel-architecture.md §15 block A; goodui.org "More Contrast", "Attention Grabs".
  • Conversion patterns: one action per page; minimized form fields; benefit-labeled button. Source: funnel-architecture.md §15 block A; goodui.org "Fewer Form Fields", "Benefit Buttons"; blog.hubspot.com landing-page best practices.
  • Mobile behavior: tap targets ≥ 44px; no horizontal scroll; sticky booking CTA. Source: funnel-architecture.md §15 block A; goodui.org Test #665.
  • Accessibility: WCAG AA — 4.5:1 body text, 3:1 large text and UI; keyboard-only focus order with visible focus ring; skip-to-content link; alt text on every image; form labels attached to fields. Source: funnel-architecture.md §15 block A; WCAG 2.x understanding documents (re-verified per §14 freshness rule).
  • Copy bar (Law 48): https://www.fresha.com/ — fetched live 2026-08-16 (HTTP 200). Bar headline construction: 4 words, action + category, no product name; subhead adds who-it-is-for + proof; CTA action-labeled; social proof = live counter + named reviews. Source: live fetch of the bar URL at build time.
