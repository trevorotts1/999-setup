# Home page wireframe (STAGE-WIREFRAMES output — layout skeleton from the design brief)

Named sections (the same names the built page's markup carries):

- Header: logo (left) + primary nav + CTA button (right)
- Hero: eyebrow, headline, subhead, CTA button, hero image (right/behind)
- Features: 3-column card grid
- Proof: testimonial band
- Footer: nav, contact, legal line

Mobile behavior: single column, stacked hero (image after text), 44px tap targets.
